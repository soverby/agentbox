# agentbox 1.2.0

This release keeps Python in the box on the newest security patch
automatically. A change to a new Python line stays a decision of the
owner.

## New

- **Python line** (PLAN §2.9). `images/agent/versions.env` pins
  `PYTHON_LINE` (3.14) and `PYTHON_LINE_EOL` (2030-10) as well as
  `PYTHON_VERSION`. `agentbox update` keeps Python in its line. The image
  build fails when `PYTHON_VERSION` is not in the line.
- **Daily patch job.** `agentbox update --python-patch --install [--at
  HH:MM]` (default 05:00) installs a host job. The job finds the newest
  patch of the line. It updates uv when the pinned uv cannot install that
  patch, then rebuilds the image, runs `doctor`, and rolls back on
  failure. It also rebuilds the derived image of each profile with
  `packages`. It posts to the Slack notification webhook when it applies
  a patch, when an update fails, when a patch is out but not installable
  yet, when a new Python line is out, and near the end of support.
- **Line change.** `agentbox update --python-line X.Y --eol YYYY-MM`
  first checks every `uv.lock` in the profile mounts, with no network,
  and refuses a line that a lock cannot install.
- **Update lock.** During an update, a scheduled fire waits up to 15
  minutes (then records exit 69, "update in progress"), and `agentbox up`
  exits 75.
- `agentbox ls` marks a running box whose image is not current with
  `image outdated`. Doctor check 22 also checks the Python update job.

## Changes

- Python in the box is 3.14.10.
- `PROJECT.md`: the box has the latest patch of a supported Python line.

## Tested paths

**Tested live** on the maintainer's host:

- A real `update --python-patch` run: 3.14.8 -> 3.14.10, doctor passed,
  derived images rebuilt, Slack posts sent. A second run reported
  "current" and posted nothing.
- The daily job install (launchd) and doctor check 22.
- The `image outdated` marker in `agentbox ls`.
- The uv probes, and the offline lock check against a lock with no
  matching wheel and against a current lock (run by the reviewer in the
  real image).

**Not tested live:** a full `--python-line` change, the uv bump path
of the patch job, and the crontab (Linux) job install.

## Upgrade

```sh
git pull
uv tool install -e ./cli --reinstall
agentbox --version   # agentbox 1.2.0
agentbox update --python-patch --install
```

A running box keeps the old image until it is recreated: end all
sessions in the box (or run `agentbox down <profile>`), then run
`agentbox up <profile>`.
