# agentbox 1.1.0

This release adds the fleet report and the fire hook, and fixes two
defects. It changes nothing in the box: no image, network, mount, or
secret delivery change.

## Tested paths

The paths in [v1.0.0](v1.0.0.md) ("Tested paths") are unchanged. In
addition:

**Tested live** on the maintainer's host:

- The fleet report (`agentbox schedule report`) as a daily launchd job
  with the `slack` output, since 2026-10-09.
- The investigator box of the fleet report, on real failed fires.

**Not tested live:**

- The fire hook (`fire_command`). It has unit tests and an end-to-end
  test of the real `_fire` path with a test hook, but no production
  consumer yet.
- The `json` and `command` outputs of the fleet report.

## New

- **Fleet report** (`agentbox schedule report`, PLAN §2.8). It finds the
  fires that were due, matches them to fire records, and classifies each
  outcome with a rule cause. It also finds idle boxes and job copies that
  differ from their source. Outputs: `stdout`, `json`, `slack`,
  `command`. An optional, locked-down investigator box explains failures
  that no rule explains. `--install` adds a daily job. Read
  [USAGE](../USAGE.md) ("Fleet report").
- **Fire hook** (`fire_command` in `config.toml`, PLAN §2.7). After each
  scheduled fire, a host command gets the outcome as JSON on stdin. Use
  it to send failures to a tracker. Read [USAGE](../USAGE.md) ("Fire
  hook").
- Fire records have `trigger` (`schedule` or `run-now`). `job.json` has
  `source` and `source_sha256`; `schedule ls` warns when the job copy
  differs from its source file.
- Doctor check 22 checks the investigator profile.

## Fixes

- A script that exits 124 itself no longer gets the message "killed after
  the timeout". Only a run that the CLI killed at its timeout gets it.
- `agentbox up` no longer fails when the first mount holds a `.git` file
  that points outside the box (a worktree or a submodule). Git setup now
  runs in the box home.

## Upgrade

```sh
git pull
uv tool install -e ./cli --reinstall
agentbox --version   # agentbox 1.1.0
```

No box restart is necessary. The fire hook is off until you set
`fire_command`.

## Known limits

The limits in [v1.0.0](v1.0.0.md) ("Known limits") are unchanged.
