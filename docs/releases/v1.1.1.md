# agentbox 1.1.1

This release fixes the agent image build and updates the tool versions in
the image. It has no CLI change.

## Fixes

- A fresh build of the agent image failed: the pinned GitHub CLI version
  (2.102.0) is no longer in its apt repository. All pins are now current.

## Changes

- Image pins: Ubuntu 24.04 digest, Claude Code 2.1.308-1, GitHub CLI
  2.103.3, Node 24.22.1, Codex 0.164.0, Pi 1.4.0, pi-mcp-adapter 7.0.0,
  Ollama 0.40.11, uv 0.13.6, Python 3.15.2.
- The MCP gateway image uses the same Node version (24.22.1). The next
  `agentbox up` rebuilds it.
- Python in the box is now 3.15. Packages that you installed with
  `pip install --user` for 3.14 are not visible to 3.15. Install them
  again.

## Tested paths

The paths in [v1.0.0](v1.0.0.md) and [v1.1.0](v1.1.0.md) are unchanged,
with one correction:

- The fire hook (`fire_command`) is now **tested live**, with a real
  consumer (Odin) on the maintainer's host.

## Upgrade

```sh
git pull
uv tool install -e ./cli --reinstall
agentbox --version   # agentbox 1.1.1
```

Image tags are content hashes, so the next `agentbox up` builds the new
image. A running box keeps the old image until it is recreated: end all
sessions in the box (or run `agentbox down <profile>`), then run
`agentbox up <profile>`. Then run `agentbox doctor <profile>`.
