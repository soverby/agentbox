# agentbox 1.3.0

This release adds Keychain secrets for plain Docker Compose stacks: the
stacks on your host that are not agentbox boxes, but still must not keep
an API key in `.env` or any other file.

## New

- **Stack secrets** (PLAN §2.11). A stack is a directory with an
  `agentbox-stack.toml` manifest: a stack name, an optional list of
  Compose files, and the secret names it needs (names only; the file is
  safe to commit).
- `agentbox secret set|rm|ls --stack <name> <NAME>` manage the secrets
  of a stack in the Keychain, under their own scope
  `agentbox/_stack/<name>/<NAME>`. A stack cannot read the secrets of a
  box or the shared secrets by default ref.
- `agentbox stack ls [-C DIR]` lists the manifest secrets and whether
  each is present. No values.
- `agentbox stack run [-C DIR] -- <command...>` fetches every manifest
  secret and runs the command, without a shell, in the stack directory,
  with `AGENTBOX_SECRET_<NAME>` and `<NAME>` in its environment. If a
  secret is missing, it prints the names and exits 2 before the command
  starts. The exit code is the command's. When the manifest lists
  `compose_files`, `COMPOSE_FILE` is set to them.
- The intended wiring is a Compose overlay file with
  `secrets: { NAME: { environment: AGENTBOX_SECRET_NAME } }` and a
  per-service `secrets:` list. Compose copies the value into the
  container at create time as `/run/secrets/<NAME>` (root, 0444). A
  restart keeps it. A plain `docker compose up` with the base file alone
  still works, without the secret. See USAGE, "Secrets for a plain
  Compose stack".
- Nothing is written to host disk: no secret directory to ignore, back
  up around, or clean up.

## Changes

- Manifest secret names follow the box rules, plus `COMPOSE_*` and
  `DOCKER_*` are refused (they would steer the docker client or compose
  in the command `stack run` execs).

## Tested paths

**Tested live** on the maintainer's host (macOS, Docker Compose 5.5):

- `secret set --stack`, `stack ls`, `stack run -- docker compose up -d`
  with a base file and an overlay: `/run/secrets/<NAME>` holds the value
  (root, 0444); `docker inspect` does not contain it; `docker compose
  restart` keeps it; `docker compose up` with the base file alone
  starts the service without `/run/secrets`; `secret rm --stack`.

**Not tested live:** the `op://` backend for a stack secret; a Linux host.

## Upgrade

```sh
git pull
uv tool install -e ./cli --reinstall
agentbox --version   # agentbox 1.3.0
```
