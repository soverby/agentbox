# agentbox 1.1.2

This release puts Python in the box back on 3.14. It has no CLI change.

## Fixes

- Python 3.15.2 (from 1.1.1) broke `uv sync --frozen` for projects whose
  lock has packages without wheels for 3.15. uv then tried a source build
  that needs the Rust toolchain, and the egress allowlist blocked the
  download. Python in the box is now 3.14.8 again.

## Changes

- Packages that you installed with `pip install --user` under 3.15 in
  1.1.1 are not visible to 3.14. Install them again.

## Upgrade

```sh
git pull
uv tool install -e ./cli --reinstall
agentbox --version   # agentbox 1.1.2
```

The next `agentbox up` builds the new image. A running box keeps the old
image until it is recreated: end all sessions in the box (or run
`agentbox down <profile>`), then run `agentbox up <profile>`.
